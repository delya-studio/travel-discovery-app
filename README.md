# 🌎 Tryple

  
  O **Tryple** é um aplicativo mobile desenvolvido para facilitar a descoberta e o planejamento de viagens, reunindo informações sobre destinos, pontos turísticos e organização de roteiros em um único lugar.

  O projeto foi desenvolvido durante o hackathon **First Commit**, utilizando React Native, Expo e TypeScript.

## O que o Tryple resolve?

Planejar uma viagem envolve decidir para onde ir, descobrir o que fazer no destino e organizar os lugares que se deseja visitar.

O Tryple foi pensado para facilitar esse processo, reunindo a descoberta de destinos e pontos turísticos com ferramentas para salvar lugares e organizar uma viagem em um roteiro por dias.

## Para quem é?

O aplicativo é voltado para pessoas que desejam pesquisar destinos, descobrir lugares para visitar e organizar suas viagens de forma mais prática.

## Funcionalidades

- Pesquisa e exploração de destinos
- Filtros por continente, país e estado
- Informações sobre destinos
- Descoberta de pontos turísticos
- Informações sobre a melhor época para visitar
- Informações de clima
- Sistema de favoritos
- Criação de viagens
- Definição do período da viagem
- Organização de pontos turísticos por dia
- Cadastro e login
- Perfil do usuário
- Gerenciamento de dados pessoais

## Tecnologias utilizadas

- React Native
- Expo
- TypeScript
- React Navigation
- AsyncStorage
- Lucide React Native
- Expo Font
- EAS Build

## Baixar o aplicativo

A versão Android do Tryple pode ser instalada diretamente pelo APK:

**[⬇️ Baixar Tryple v1.0.0](https://github.com/delya-studio/travel-discovery-app/releases/tag/v1.0.0)**

Na página do Release, baixe o arquivo `Tryple.apk` em **Assets** para iniciar o download. Após o download, abra o arquivo no dispositivo Android e siga as instruções de instalação.

> Não é necessário instalar Node.js, npm ou Expo para utilizar o aplicativo Android. Essas ferramentas são necessárias apenas para executar o projeto a partir do código-fonte.

## Como executar o projeto

### Pré-requisitos

Para executar o projeto a partir do código-fonte, você precisa ter instalado:

- [Node.js](https://nodejs.org/)
- npm
- Git

### 1. Clone o repositório

```bash
git clone https://github.com/delya-studio/travel-discovery-app.git
```

### 2. Acesse a pasta

```bash
cd travel-discovery-app
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o projeto

```bash
npx expo start
```
Depois, execute o aplicativo em um dispositivo ou ambiente compatível com Expo.

## Armazenamento de dados

O Tryple utiliza `AsyncStorage` para armazenar localmente informações relacionadas ao usuário, como dados de cadastro, sessão e favoritos.

A autenticação e o armazenamento utilizados nesta versão têm finalidade de demonstração e aprendizado durante o hackathon e não representam uma implementação de autenticação para produção.

## Sobre o desenvolvimento

O Tryple foi desenvolvido como um projeto de aprendizado durante o hackathon First Commit, com foco no desenvolvimento mobile e na aplicação prática de conceitos de React Native, Expo e TypeScript.

Durante o desenvolvimento, foram aplicados conceitos como navegação entre telas, componentes reutilizáveis, armazenamento local, gerenciamento de estado, criação de interfaces e distribuição de um aplicativo Android.
